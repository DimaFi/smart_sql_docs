# Требования к оформлению научного отчёта НИР

Параметры вёрстки зафиксированы в `report/sgu-nir.cls`, титульный лист — в `report/titlepage.tex`. Все персональные реквизиты необходимо заполнить до сдачи работы.

| Элемент | Принятое правило | Где настраивается |
|---|---|---|
| Титульный лист | Сведения о вузе, практике, студенте, сроках и руководителе | `report/titlepage.tex` |
| Содержание | Отдельная страница; заголовки и номера страниц со связующими точками | `\tableofcontents` в `report/main.tex` |
| Введение | На новой странице, заголовок по центру | `report/sgu-nir.cls` и `report/sections/introduction.tex` |
| Основная часть | Пять тематических разделов с подразделами и подпунктами по необходимости | `report/sections/` |
| Заключение | На новой странице; только выполненные этапы и обоснованные выводы | `report/sections/conclusion.tex` |
| Источники | Автоматический нумерованный список; 20 научных публикаций | `biblatex-gost` и `report/bibliography/references.bib` |
| Нумерация страниц | Номер справа внизу, без отображения номера на титульном листе | `fancyhdr` в классе |
| Основной текст | Times New Roman, 14 пт; по ширине; отступы слева и справа 0 см; красная строка 1,25 см; интервалы до и после абзаца 0 пт; межстрочный интервал 1,5 | `report/preamble.tex` и класс |
| Нумерованные заголовки | Times New Roman, 14 пт, полужирный; номер и заголовок через пробел; отступ первой строки 1,25 см | `report/sgu-nir.cls` |
| Поля | Левое — 30 мм, правое — 15 мм, верхнее и нижнее — 20 мм | `geometry` в классе |
| Рисунки и таблицы | Нумерация и подписи средствами LaTeX | `caption` в классе |

## Перед сдачей

1. Заполнить все реквизиты на титульном листе и проверить установленные формулировки практики.
2. Уточнить у научного руководителя применимость ГОСТ 7.32–2017 и локальных требований факультета к конкретному виду работы.
3. Проверить корректность библиографических реквизитов и действительность DOI по издательским записям; подробности в `docs/source-audit.md`.
4. Скомпилировать PDF, проверить правильность ссылок и нумерации, провести визуальный просмотр страниц.

## Сборка

```bash
python3 scripts/check_bibliography.py
cd report
latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex
```

GitHub Actions автоматически выполняет проверку и сборку PDF при изменениях в ветке `main`.
