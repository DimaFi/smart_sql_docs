## Приоритеты ручной проверки

1. Открыть DOI каждой статьи и убедиться в совпадении заголовка, авторов, года, тома и номера. На 11.11.2026 страницы некоторых статей на домене `journals.eco-vector.com` временно отвечали ошибками; их данные были сверены с поисковыми выдержками издателя, а не с успешно открытым полным текстом.
2. Уточнить язык и научные индексы журналов по eLIBRARY/РИНЦ и актуальным спискам ВАК, не объявляя наличие индекса без подтверждения.
3. Для `morozov2020`, `filimonov2022`, `miraz2021`, `almuhammed2022` вместо страниц используется идентификатор статьи.
4. Проверить у научного руководителя допустимость включения статьи на русском языке из белорусского издания «Доклады БГУИР» в требуемые «2/3 русскоязычных»; если нужна именно страна издателя РФ, заменить эту запись российской рецензируемой статьёй.
5. До финальной сдачи подтвердить точный вариант титульного листа по методическим рекомендациям кафедры и требованиям научного руководителя.
