# SmartSQL — отчёт по учебной практике «Научно-исследовательская работа», 1 семестр

Это **научно-теоретическая**, а не программно-практическая часть магистерской работы о системе SmartSQL.

**Образец оформления:** PDF Алёны (29 страниц), приложенный пользователем в переписке и упомянутый в [Issue #1](https://github.com/DimaFi/smart_sql_docs/issues/1). В `docs/layout-comparison.md` перечислены правила сопоставления. Текст и тема Алёны НЕ копировались.

## Что включено

- титульный лист формата «ОТЧЕТ О ПРАКТИКЕ», как в образце, с полями для заполнения;
- содержание, введение, **5 глав**, заключение, список научных источников;
- оригинальная концептуальная схема обработки пользовательского запроса (не экспериментальный результат);
- **20 журнальных публикаций** (16 русскоязычных), у всех указан DOI, все процитированы;
- автоматические библиография и перекрёстные ссылки через `biblatex-gost` + Biber;
- сборка PDF локально и в GitHub Actions.

**Внимание!** В исходном PDF Алёны нет раздела литературы в содержании; это воспроизведено. Поля слева установлены **30 мм**, как предусмотрено ГОСТ 7.32–2017, хотя в образце визуально около 25 мм. Учитывайте требования научного руководителя и кафедры. Фактические даты практики, ФИО, группа, кафедра, руководитель намеренно не придуманы.

## Быстрый старт

Установите TeX Live с XeLaTeX, Biber, `biblatex-gost`, `latexmk` и шрифтом Tinos (пакет `fonts-croscore` в Debian/Ubuntu).

```bash
python3 scripts/check_bibliography.py
cd report
latexmk -xelatex -interaction=nonstopmode -halt-on-error main.tex
```

Готовый PDF: `report/main.pdf`. Для очистки: `latexmk -c`.

На Windows можно использовать TeX Live или MiKTeX и выполнить те же команды из PowerShell после установки Python и необходимых пакетов. Шрифты должны быть доступны системе.

## Как персонализировать документ

Откройте `report/titlepage.tex` и заполните команды `\StudentGroup`, `\StudentFIO`, `\DepartmentName`, `\PracticeDuration`, `\PracticeStart`, `\PracticeEnd`, `\SupervisorPosition`, `\SupervisorName`. **Чужие данные из образца не копируйте.**

Материал по разделам расположен в `report/sections/`. Источники — `report/bibliography/references.bib`, реестр ссылок на издателей и ограничения аудита — `docs/source-audit.md`. Проверка количества, полноты полей и ссылок — `scripts/check_bibliography.py`.

## GitHub Actions

После push в `main` или ручного запуска `Actions > Build NIR PDF` создаётся артефакт `SmartSQL-NIR-Report`. Пока выполнение самого workflow в GitHub не подтверждено, но локальная компиляция проверяется перед публикацией.

## Научная добросовестность

- Объект, предмет, цели и задачи практики разделены от цели всей магистерской работы.
- Нет выдуманных результатов экспериментов, публикаций автора и подтверждений научной новизны.
- DOI и библиографические реквизиты нуждаются в **передсдаточной проверке у издателей/eLIBRARY**; структурный скрипт не является онлайн-валидацией DOI.
- Проверка статуса журналов в ВАК/РИНЦ/Scopus/WoS не завершена; наличие DOI не подтверждает индексацию.
- Точное сходство с PDF Алёны достигнуто на уровне структуры/характера оформления; документ не является пиксельной копией, прежде всего из-за поля по ГОСТ и иного объёма текста.
